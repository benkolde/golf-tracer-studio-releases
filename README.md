# Golf Tracer Studio

Downloads for [Golf Tracer Studio](https://golftracer.ai), golf shot tracers for video editors.

**[Download the latest version for Mac](https://github.com/benkolde/golf-tracer-studio-releases/releases/latest/download/GolfTracerStudio.dmg)**: Apple Silicon (M1 or later), signed and notarized by Apple.

The app needs a license key. [Get one at golftracer.ai](https://golftracer.ai/pricing.html).

This repository holds release downloads only.
